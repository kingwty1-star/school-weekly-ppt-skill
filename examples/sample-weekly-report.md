# 2026W21 学习周报

## 一、本周学习概览

本周围绕 MATLAB 控制仿真复现工程进行学习，重点是理解入口函数、参数结构体、仿真主循环和控制器计算函数。

## 二、本周主要学习内容

- 理解 `runPaperReplication.m` 的总调度作用。
- 掌握 `params` 参数结构体的分层含义。
- 看懂仿真主循环如何按 `dt` 推进状态。
- 区分控制器输出 `v` 和执行器输入 `u`。
- 初步读懂 `evaluateController` 中 `yd -> z1 -> alpha1 -> z2 -> v -> dEtaHat` 的变量流。

## 三、本周关键收获

本周最大的收获是从“知道代码在哪里”推进到“知道关键变量如何流动”。其中 `z1 = xHat1 - yd` 表示估计输出与参考轨迹之间的跟踪误差，事件触发条件决定 `u` 是否更新为 `v`。

## 四、本周问题与修正

1. `alpha1` 不是最终控制输入，而是第一层虚拟控制器。
2. `dEtaHat` 不是 `etaHat` 本身，而是自适应参数的变化率。
3. `rk4Step` 负责状态推进，不负责事件触发判断。

## 五、下周学习计划

1. 对照论文公式标注 `evaluateController.m` 的代码位置。
2. 继续理解 RBF 补偿项 `phi1` 和 `phi2` 的工程含义。
3. 分析 `gamma` 和 `theta` 对触发频率的影响。
4. 准备进入仿真图形复现阶段。
